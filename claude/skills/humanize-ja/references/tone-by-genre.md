# 媒体別トーンガイド

書き換え前に「何の文章か」を判定し、その媒体に合うトーンへ寄せる。共通の土台は **砕けすぎないビジネス日本語**。媒体が違っても、事実・専門用語の尊重と「削る・具体化する」原則は変わらない。

## 判定の手がかり
- 敬体（です・ます）か常体（だ・である）か
- 一人称：弊社／当社／私たち／なし
- 読み手：社内メンバー／既存顧客／採用候補者／不特定の読者
- 形式：連続した散文か、スライドの断片か、お知らせの定型か
- 既存のスタイル（社内ガイド・過去の同種文書）があればそれが最優先

判定できないとき **だけ** ユーザーに確認する（例：社内向けか社外向けか）。基本は本文から読み取る。

## 社内説明文書・お知らせ・議事録

- **基調**：敬体、簡潔、結論先行。読み手は同僚で前提知識を共有している。
- **効くこと**：冒頭に結論・対象者・期限を置く。背景説明は後ろに回すか削る。決定事項とお願い事項を分ける。
- **避けること**：長い前置き、曖昧な主語（「〜が必要とされている」の受け身）、過剰な敬語。
- 例：「下記のとおり運用を変更します。対象は開発チーム、適用は 6/1 からです。」を先頭に。

## ブログ記事（note / はてなブログ）

note・はてなの編集者ピックアップや人気企業ブログに共通する、選ばれる文章の傾向：

- **一次体験と固有名詞。** 借り物の一般論ではなく、自分が見た・やった具体を書く。固有名詞・数字・場面が信頼を生む。
- **素直な語り口。** 等身大の声。背伸びした美辞麗句より、率直で具体的な記述。
- **誠実なタイトルと構成。** 煽らない、結論を引き延ばさない。読み始めてすぐ「何の話か」が分かる。
- **読み手への奉仕。** 読者が得る情報・できるようになることを明確に。書き手の自己満足で終わらない。
- **基調**：敬体ベース。テーマによっては常体や軽い口語も可だが、ビジネス文脈では砕けすぎない。
- **避けること**：「本記事では〜」「いかがでしたか」のテンプレ、中身のない網羅、煽り見出し、AI 的な均質リズム。
- 企業ブログ（技術ブログ等）の場合は、技術用語を正確に保ちつつ、決定の理由・つまずき・学びという一次情報を前に出す。
- **読み物系では「崩し」を許容する。** 結論までの葛藤・思考過程・軽い脱線は、人間らしさとして残してよい。原文にある主観・スタンス・感情の描写は消さず、むしろ前に出す（→ `writing-principles.md` D 節）。整えすぎて無菌室のような文章にしない。

## 技術記事・技術書原稿・解説文

- **基調**：敬体または常体（原文に従う）。論証の正確さを最優先する。
- **効くこと**：パラグラフライティング（一段落一トピック、段落頭で話が分かる）、因果の機構を一文で示す、断定と推量の正確な書き分け、術語の一貫使用。→ `writing-principles.md` C 節。
- **避けること**：LLM 空句（「正面から扱う」「掘り下げる」「多角的」）、意義づけの付け足し（「〜を浮き彫りにしており」）、曖昧な出典、「必ず／完全に」の過大な保証、劇的な演出。
- ブログ系と違い、論理の崩しは許容しない。厳密に整えたうえで、文末のリズムと具体例で読みやすさを作る。

## 採用文章（求人・募集要項・採用ピッチ・社員紹介）

- **基調**：敬体、誠実、候補者目線。読み手は「ここで働く自分」を想像している。
- **効くこと**：等身大の実態（良い面も課題も）、具体的な仕事内容・チーム構成・技術スタック、固有名詞、数字。「なぜこの仕事が面白いか」を具体で語る。
- **避けること**：「成長できる環境」「風通しの良い社風」などの抽象テンプレ、誇張、どの会社にも当てはまる美辞麗句。AI 採用文の典型症状なので最優先で具体化する。
- 例：「裁量のある環境」→「四半期ごとに自分でテーマを決め、設計から運用まで一気通貫で担います」。

## HTML スライド・プレゼン資料

- **基調**：体言止め・短句中心。一枚に一つのメッセージ。
- **効くこと**：削る。文を句にする。対比・並列で見せる。数字を大きく。話して補う前提で、文字は要点だけ。
- **避けること**：一枚への詰め込み、長い文、文末の冗長（「〜することができます」等）、説明的すぎる箇条書き。
- HTML を直すときは、タグ・クラス・レイアウト構造を壊さず、テキストノードの文言だけ書き換える。スライドのデザイン意図（強調・改行位置）を尊重する。

## メール・チャット（社外／社内）

- **社外メール**：敬体、簡潔、用件先行。過剰なクッション言葉を削る。件名で用件が分かるように。
- **社内チャット**：敬体だが軽め。一文を短く、結論から。長文は箇条書きで構造化してよい。

## 共通の禁則（どの媒体でも）
- タメ口・過度な煽り・顔文字／絵文字の乱用には寄せない（媒体が明示的に許す場合の最小限を除く）。
- 著者の声・固有の言い回しを消さない。整えるが、別人の文体にしない。
- 事実・専門用語・固有名詞を保護する。
