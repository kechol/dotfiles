# 日本語表記の統一ルール

『日本語表記ルールブック』（日本エディタースクール）に準拠した、推敲時の表記統一の指針。**まず原文の方針を尊重し、その方針内で揺れを揃える** のが基本。媒体ごとの既存スタイル（社内ガイド等）があればそれを優先する。

## 1. 漢字をひらく／とじる

「ひらく」＝かなにする。「とじる」＝漢字にする。日本語は本来の意味から離れて補助的に使う語をかなに開くと読みやすい。AI 文章はとじすぎ（黒々しい）の傾向があるので、次の語は **ひらく** を基本にする。

### ひらくのが基本（形式名詞・補助動詞・副詞・接続詞など）

| とじ（避ける） | ひらく（推奨） |
|---|---|
| 事 | こと |
| 物・者 | もの（抽象） |
| 時 | とき（場合の意） |
| 為 | ため |
| 様々 | さまざま |
| 出来る | できる |
| 無い | ない |
| 良い | よい（補助的用法） |
| 等 | など |
| 迄 | まで |
| 又 | また |
| 更に | さらに |
| 既に | すでに |
| 是非 | ぜひ |
| 殆ど | ほとんど |
| 全て | すべて |
| 因みに | ちなみに |
| 頂く（補助動詞） | いただく（例：ご確認いただく） |
| 下さい（補助動詞） | ください（例：ご確認ください） |
| 致します（補助動詞） | いたします（例：お願いいたします） |
| 来る・行く（補助動詞） | 〜してくる／〜していく |
| 居る（補助動詞） | 〜している |

> 動詞・名詞として実体の意味で使うときはとじる：「時を待つ」「物を運ぶ」「頂上」「来週」「物事」。補助的・形式的に使うときだけひらく。

### とじるのが基本
- 実質的な意味を持つ動詞・名詞・形容詞は漢字：必要・実現・確認・対応・課題・改善 など。
- ひらきすぎても読みにくい。バランスが目安（漢字 3 割前後が読みやすいとされる）。

## 2. 数字

- **算用数字（半角）を基本にする。** 数量・順序・年月日：「3 つ」「2025 年」「第 1 章」「40 時間」。
- **漢数字を使う場面**：慣用句・固有名詞・概数で語になっているもの：「一つひとつ」「四半期」「数十人」「一石二鳥」「第三者」。
- 同一文書内で算用と漢数字を混在させない（慣用句を除く）。
- 桁区切りは原則カンマ（1,500 件）。媒体方針に従う。

## 3. 約物（やくもの＝記号）

- 句点は「。」読点は「、」。横書きで媒体が「，．」指定ならそれに従うが、混在させない。
- **三点リーダーは「……」と 2 つ重ねる。** 「…」1 つや「・・・」は避ける。
- **ダッシュは日本語の地の文では原則使わない。** em ダッシュ「—」や全角ダッシュ「――」での言い換え・挿入（「多角的な視点—すなわち〜」）は AI 生成文の顕著な徴候。同格・補足の挿入は（）に、言い換え・敷衍は句点で二文に分けるか読点でつなぐ。文学的表現などでどうしても使う場合のみ「——」と 2 つ重ね、ハイフン・長音記号で代用しない。範囲を示す en ダッシュや英語の複合語（Curry–Howard など）、コードブロック・書誌情報は対象外。
- **コロン「：」の直後に半角スペースを入れない。** 「重要な要素： テクノロジー」の「： 」は英語癖の残留。そもそも「目的：」「背景：」のようなラベル列挙は減らし、文で書く。用語と定義を並べる箇条書きでは「**用語**：説明」の形でよい。
- **全角スラッシュ「／」で概念を並列しない。** 「A／B」は「A と B」「A や B」に開くか、どちらか一方に絞る。矢印（→）や疑似コード風の表記も地の文では避け、文章として書く。
- 括弧：会話・引用・強調は「」、その中の入れ子は『』、補足は（）。書名・作品名は『』。いずれも多用しない（→ `ai-tells.md` 12 節）。
- 中黒「・」は外来語の区切りや固有名詞内部に。語の並列での多用は避け、読点や「と」で繋げるなら繋ぐ。
- 感嘆符「！」疑問符「？」はビジネス文では抑制。使うなら全角、直後に全角空け（媒体方針による）。
- **Markdown 記法の残留を除去する。** プレーンテキストや HTML 中の `**太字**`・`##`・`- ` などの生記号は消し忘れ。媒体に合った装飾に変換するか外す。

## 4. カタカナ・外来語

- **長音符号の方針を統一する。** 慣用に従い、原則として末尾は長音を付ける現代表記：「コンピューター」「サーバー」「ユーザー」「メンバー」。ただし IT 業界の社内慣行で「サーバ」「ユーザ」等を使う場合は **原文・社内方針を優先** し、文書内で統一する。
- 専門用語・製品名のカタカナ表記は原文を尊重する（勝手に開かない・変えない）。
- 複合語の中黒：「クラウドセキュリティ」など定着語は詰める。意味の切れ目で必要なときだけ中黒。

## 5. 送り仮名・その他

- 送り仮名は本則に従う：「行う」「表す」「現れる」「受け付け（名詞）／受け付ける（動詞）」。
- 「ら抜き」「い抜き」を避ける：「見れる→見られる」「食べてる→食べている」。
- 重ね言葉（二重表現）を避ける：「各〜ごと」「まず最初に」「約〜程度」「過半数を超える」。
- くり返し符号「々」は同字反復に使う（人々・日々）。「学問問題」のような熟語境界では使わない。
- 全角・半角を統一：英数字・記号は原則半角、和文との間は媒体方針で半角空け or 詰めを統一。

## 運用メモ

- 表記は **正しさより一貫性**。一文書内で揺れていないことが最優先。
- 社内の表記ガイド・既存文書のスタイルがあれば、本ルールより優先する。
- 専門用語・固有名詞・コード・コマンドは表記統一の対象外（原文どおり保護）。
