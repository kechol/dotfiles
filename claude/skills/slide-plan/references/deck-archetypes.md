# デッキ・アーキタイプ（用途別の分量・トーン既定値）

用途によって「1枚の情報量・総枚数・トーン・向いたストーリー型・投影/読み物」の既定値が変わる。
入力から合うアーキタイプを選び、以降の構成案をこの密度で組む。迷う場合は AskUserQuestion で選ばせる。

数値は目安。実際の制約（持ち時間・枚数指定）が優先。

## アーキタイプ一覧

### 1. 戦略発表（経営方針・全社共有）
- **目的**: 方針を示し納得と当事者意識を得る
- **利用シーン**: 投影中心（読み物版を別途作ることも）
- **枚数/時間**: 本論 15〜30 枚 / 30〜60 分。1枚あたり約 2〜3 分
- **1枚の情報量**: 中。キーメッセージ＋根拠図解1つ
- **トーン**: 説得的・骨太。ビジョンと数値の両輪
- **向いたストーリー型**: SCQA → ピラミッドで論拠展開 → Call to Action
- **外せない要素**: 現状認識（同意できる事実）/ 変化と危機感 / 目指す姿 / 打ち手 / 求める行動

### 2. ライトニングトーク（5分・1メッセージ）
- **目的**: 1つの主張を印象づける
- **利用シーン**: 投影のみ
- **枚数/時間**: 5〜10 枚 / 5 分。1枚あたり 30〜60 秒
- **1枚の情報量**: 少。大字（キーメッセージ 13 文字前後）、図か写真1点
- **トーン**: 軽快・印象重視。余白多め
- **向いたストーリー型**: 1メッセージ集中（つかみ→主張→根拠1つ→締め）
- **外せない要素**: 開始 30 秒のつかみ（数字×質問）/ ただ1つの主張 / 記憶に残る締め

### 3. 配布資料・読み物（ドキュメント）
- **目的**: 単体で読んで理解・意思決定させる
- **利用シーン**: 読み物（投影しない前提）
- **枚数/時間**: 制約緩め。網羅性優先
- **1枚の情報量**: 多。自己完結（説明文・脚注・出典を省かない）
- **トーン**: 精緻・網羅的。F 型レイアウト（見出し左寄せ）
- **向いたストーリー型**: 論点網羅型 / 空・雨・傘。見出しだけ読んで通るホライゾンタルロジック
- **外せない要素**: 各論点の結論と根拠 / 前提・定義 / 出典 / 想定QAへの答え
- **注意**: 投影用スライドと兼用しない。兼用するとどちらも中途半端になる

### 4. 営業提案（顧客向け）
- **目的**: 顧客の課題を解決策で解き、決断を促す
- **利用シーン**: 投影＋置いていく資料
- **枚数/時間**: 本論 10〜20 枚 / 3〜30 分（場面による）
- **1枚の情報量**: 中。顧客目線のベネフィットを前面に
- **トーン**: 顧客目線・ベネフィット訴求。感情（共感→信頼→納得→決断）を設計
- **向いたストーリー型**: 課題→原因→解決→効果
- **外せない要素**: 顧客の課題の言語化（共感）/ 解決策 / 機能→メリット→未来像 / 実績・客観的根拠（信頼）/ 費用対効果 / 次アクション
- **注意**: 詳細な裏付けは Appendix へ逃がし本編の密度を守る

### 5. 経営会議・意思決定（決裁を仰ぐ）
- **目的**: 論点を提示し判断を得る
- **利用シーン**: 投影＋事前配布
- **枚数/時間**: 本論 5〜15 枚 / 5〜15 分。決裁者の時間は短い前提
- **1枚の情報量**: 中。結論先出し、数値が主拠り所
- **トーン**: 端的・論点駆動。無駄を削り結論到達を最短化
- **向いたストーリー型**: 結論 → 根拠 → 選択肢（2案提示）
- **外せない要素**: 決めてほしいこと（論点）/ 推奨案と対抗案の2案 / 財務的視点・実現可能性・理念整合 / リスクと対策 / 想定QA
- **注意**: ネガティブ情報も先回りして誠実に開示する

### 6. 勉強会・技術共有（教育・学習）
- **目的**: 概念や手法を理解・習得させる
- **利用シーン**: 投影＋後で見返す資料
- **枚数/時間**: 制約緩め。理解の段階に合わせる
- **1枚の情報量**: 中。図解と例を多用
- **トーン**: 教育的・段階的。予告→本論→まとめの反復
- **向いたストーリー型**: 概念 → 詳細 → まとめ（PREP や解説型）
- **外せない要素**: 全体像（地図）/ 用語の定義 / 具体例・デモ / まとめと次の一歩

## 選び方のヒント

- 入力に「経営会議」「決裁」「承認」があれば **5**、「顧客」「提案」「見積」があれば **4**。
- 「5分」「LT」「軽く」なら **2**、「読んでもらう」「送っておく」「配布」なら **3**。
- 「全社」「方針」「キックオフ」なら **1**、「勉強会」「共有会」「入門」なら **6**。
- **優先順位**: 判断が競合したら「**持ち時間・形式の指定（5分/LT/配布）> 場の名称（勉強会/全社会議）**」で決める。
  例:「勉強会でLT・5分」は場が勉強会でも **2（ライトニングトーク）** を採る。
- 複数該当・不明なときは AskUserQuestion で 2〜4 択にして選ばせる。
- 同じ内容でも「投影用」と「読み物用」は別アーキタイプ。両方要るなら 2 本立てを提案する。

## 枚数の逆算

持ち時間の指定があれば、既定枚数より逆算を優先する: **枚数 ≒ 持ち時間 ÷ 1枚あたり目安分**（表紙・まとめは別枠）。

| アーキタイプ | 1枚あたり目安 | 例（持ち時間→本論枚数） |
| --- | --- | --- |
| 戦略発表 | 約 2〜3 分 | 15分 → 5〜7枚 / 30分 → 10〜15枚 |
| ライトニングトーク | 約 30〜60 秒 | 5分 → 5〜9枚 |
| 営業提案 | 約 1.5〜2 分 | 15分 → 7〜10枚 |
| 経営会議 | 約 1〜1.5 分（+質疑） | 10分 → 5〜8枚 |
| 勉強会 | 約 1.5〜2 分 | 30分 → 12〜18枚 |
| 配布資料 | （時間非依存。論点数で決める） | 論点1つ＝1〜2枚 |
