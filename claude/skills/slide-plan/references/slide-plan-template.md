# slide-plan.md 出力テンプレート

このテンプレートを複製して各スライドの構想を埋める。`---` 区切りで 1 セクション＝1 スライドに対応させ、
後段の実スライド化（Marp / PowerPoint / HTML 等）にそのまま渡せる形を保つ。プレースホルダ `[...]` は「ユーザーがこれから埋める箇所」を表す。

---

## テンプレート本体（この下をコピーして使う）

```markdown

> 指示すれば実スライド化に進めます（Marp / PowerPoint / HTML など、そのとき選ぶ形式で作成）。
> この段階では構成のみ。完成スライドはまだ作りません。
```

## 記入のコツ

- **タイトルの縦読み**: S1→S2→… とタイトルだけ上から読んで論旨が通るか最後に確認する（ピラミッド構造）。
  通らなければ順序かタイトルを直す。
- **図解ナッジは具体に**: 「グラフを入れる」ではなく「何を軸に、何を並べ、どの1点を強調するか」まで書くと、
  ユーザーが素材を用意しやすく、後段の作図もぶれない。
- **表紙・目次・まとめ・Appendix**: アーキタイプによって要否が変わる。テンプレでは本論スライドを中心に置き、
  表紙（タイトル/日付/発表者）と結び（まとめ/Next Action）は最初と最後に S0 / S-last として足す。
- **1スライド1メッセージ**: 1枚に主張が2つ入りそうなら分割する。分割案もナッジに書いておく。
