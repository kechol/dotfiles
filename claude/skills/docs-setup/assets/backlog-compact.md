### `{{DOCS_DIR}}/backlog.md` — やること

**Epic ごとにセクションを分け、タスクはチェックボックス1行** で管理します。

- 完了したら `- [x]` にする。**移動も削除もしない**（Epic の中にそのまま残す）
- 受け入れ条件などの詳細は、**着手するタスクにだけ** ネストで書き足し、完了時に消す
- 1タスクは **1セッション・1PR で終わる大きさ** にする。終わらないなら分割する
- 実装計画は **着手直前** に書き、**承認を得てからコードを書く**

#### 書式

````markdown
# Backlog

## Epic: 検索機能

- [x] T-009 インデックス設計 — tsvector 列 + GIN
- [ ] T-012 検索APIの追加  **(doing)**
  - スコープ外: 形態素解析、ランキング調整
  - [ ] `GET /search?q=` が 200 と JSON 配列を返す
  - [ ] 該当なしのとき空配列（404 にしない）
  - [ ] `npm test` が通る
- [ ] T-013 検索結果のページング — `limit` / `offset`

## Epic: 認証

- [ ] T-014 ログインフォーム
- [ ] T-015 セッション更新
````

- 進行中は `**(doing)**` を付ける。同時に doing にするのは原則1つ
- ID は通し番号。Epic をまたいでも振り直さない
- Epic 名は変えない（変えると commit の参照とずれる）

#### 分割を始める基準

**どれか1つでも当てはまったら `{{DOCS_DIR}}/backlog/` へ分割する。** 当てはまるまでは単一ファイルでよい。

| 基準 | しきい値 |
|---|---|
| ファイル行数 | 500行を超えた |
| Epic の数 | 10個を超えた |
| 未完了タスクの数 | 30件を超えた |
| 同時編集 | 複数人・複数エージェントが並行して触りコンフリクトが発生した（**行数に関係なく即分割**） |

完了タスクは行数に含まれますが、そのまま残します（過去の実績が文脈になる）。
完了した Epic が積み上がって読みにくくなったら、分割より先に **Epic 単位のアーカイブ**を検討してください。

分割時は **Epic = 1ファイル**（`{{DOCS_DIR}}/backlog/search.md` など）にするのが自然です。移行は一度にやり、
**ID は絶対に振り直しません**（commit trailer が全部無効になる）。1タスク1ファイルへ移す場合は
`T-012` → `task-012-<kebab>.md` と番号を保ち、対応関係をこのルールに1行残します。
