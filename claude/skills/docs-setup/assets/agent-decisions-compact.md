### decisions.md
- 1決定 = 1行。`- **D-NNN** (YYYY-MM-DD, Status) 決定内容` を**末尾に追記**
- **既存の行は書き換えない。** Status 部分のみ変更可
- 覆すときは新しい行を追記し、古い行を `Superseded by D-NNN` にする
- 実装を始める前に decisions.md を読み、既存の決定に反する実装をしない。
  反する必要があるなら、まず報告して指示を仰ぐ
- アーキテクチャ・依存・データモデル・公開API・認証に関わる選択をしたら、
  コードを書く前に1行追記する（Status: Proposed）
